# learn-python-2026
Learning materials for the Python Crash Course part of IDSP @ ITU, fall 2026

__Welcome to the Introduction to Programming and Data Science (IDSP) 2026__

This repository contains the course material for the Python Crash Course - part I of [Introduction to Data Science and Programming (IDSP)](https://learnit.itu.dk/course/view.php?id=3025953) at [ITU](https://en.itu.dk/), fall semester 2026.

# Course structure
The Python crash course consists of 11 units. Each unit consists of a lecture and exercises. All material for each unit is stored in the folder of the same name (class01, class02, and so on). To complete a class, go first through the lecture (new material, with short in-class hands-on exercises) and then through the corresponding exercises (longer, self-paced practicing of the lecture material).

# Crash course contents - what you will learn
After completing the course, you will be familiar and comfortable with the following topics:
* Working with Anaconda, Jupyter notebook
* Python objects (the "building blocks" of Python)
* Fundamental data types: `int`, `float`, `str`, `bool`, further data types and how to work with them: `list`, `set`, `dict`, `tuple`
* Operators (mathematical, assignment, comparison)
* Boolean logic and operations
* Conditional statements (if/else/elif)
* Loops: `for` and `while`
* Writing your own functions
* Interacting with the command line interface (CLI)
* Writing your own Python scripts
* Running Python scripts from the command line interface (CLI)
* Creating interactive Python scripts with user input
* Reading in and processing data in different file formats
* Importing, using, and creating Python modules
* Installing, importing, and using Python packages and libraries
* Data wrangling with `pandas`
* Package management with `conda`
* Measuring the runtime of your code
* Sending HTTP requests with `requests` and webscraping with `beautifulsoup4`

# Additional resources
In the folder `books`, you will find the PDF versions of 3 books: 
1. "Python Crash Course" by Eric Matthes
2. "Python Projects For Beginners" by Connor Milliken
3. "Automate the Boring Stuff" by Al Sweigart.
All three books are great to look up any of the topics from this Python course. Which one will speak most clearly to you is a manner of personal taste, and depending on the topic. Therefore, if you are struggling with a topic or want a more in-depth explanation, make sure to check it out in any or all of the three books!

# Exercises
Exercise 01 is all about installing the necessary software for this course. From exercise 02 onwards, you will find 2 versions of each exercise notebook: exerciseXX and (uploaded later) also exerciseXX_solved. Start with exerciseXX, and give yourself a couple of hours (and plenty of tries!) to solve the exercises on your own, before you check out the exerciseXX_solved notebook. If something is unclear please don't hesitate to ask the TAs.
